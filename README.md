# Дисковое key-value хранилище на Go

## Задание

Поэтапно собрать консольное хранилище пар «ключ — значение» и разобраться, как оно сохраняет данные после завершения программы. Начальная версия работает только в памяти. Затем добавляются журнал операций, восстановление недописанных записей, контрольные суммы, снимки состояния и блокировка от одновременного открытия двумя процессами.

На каждом этапе нужно провести опыт, объяснить обнаруженную проблему и повторить проверку после изменения программы.

## С чего начать

Откройте [практикум для macOS](docs/PRACTICUM.md). В нём находятся настройка Go, весь код, команды и ожидаемые результаты. Следуйте разделам по порядку. Готовые блоки создают необходимые файлы, знание Go заранее не требуется.

Чтобы скачать материалы, нажмите **Code → Download ZIP**, распакуйте архив и откройте `docs/PRACTICUM.md`. Действия с Terminal описаны в начале практикума.

## Результат

После выполнения получится программа `bin/kv`, которая умеет записывать, читать и удалять значения, искать записи по началу ключа, выполнять пакет изменений и создавать снимок базы. Данные хранятся в выбранной папке на диске и восстанавливаются при следующем запуске.

Нужно пройти опыты всех шести этапов, запустить тесты итоговой версии и записать видео выполнения работы. Отдельный письменный отчёт не требуется.

**Среда:** macOS, Go. Внешние библиотеки и сервисы не нужны.

**Трудоёмкость:** 10–12 часов, включая настройку окружения, выполнение опытов, тестирование и запись видео.

## Как оценивается работа

В практикуме приведены [критерии Б−, Б, Б+, П и Э](docs/PRACTICUM.md#assessment). Б — весь основной маршрут и работающий инструмент. Для Б+ нужно объяснить механизмы на результатах опытов. П добавляет разбор сбоев при создании снимка, Э — собственный сценарий с автоматическими проверками. Все условия каждого уровня перечислены в таблице критериев.
